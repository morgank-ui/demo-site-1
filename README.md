# Demo Site 1

A responsive personal website starter with a laptop session tracker. Open `index.html` in a browser to preview it.

## Laptop session tracker

- A session starts automatically when you open the website, or choose **Start a new session** after finishing one.
- Choose **Finish session** when you are done to save the end time and total duration.
- Choose **Enable hourly notifications** and allow notifications in your browser to receive desktop reminders.
- Keep the page open for hourly reminders. For local preview, use a local web server such as VS Code Live Server; desktop notifications generally require HTTPS or localhost.
- The timer measures the time between the start and finish buttons, so it includes breaks or time while the computer sleeps. It does not detect actual keyboard/mouse activity.

Session information is saved in this browser local storage and is not sent to a server.

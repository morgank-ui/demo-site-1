# Demo Site 1

A responsive personal website starter with a laptop session tracker. Open `index.html` in a browser to preview it.

## Laptop session tracker

- Choose **Start session** when you begin and **Finish session** when you are done.
- The page records the start time, finish time, and elapsed session duration in this browser on this device.
- Allow browser notifications when prompted to receive a desktop reminder every hour.
- Keep the page open for hourly reminders. For local preview, use a local web server such as VS Code Live Server; desktop notifications generally require HTTPS or localhost.
- The timer measures the time between the two buttons, so it includes breaks or time while the computer sleeps. It does not detect actual keyboard/mouse activity.

Session information is saved in this browser's local storage and is not sent to a server.
